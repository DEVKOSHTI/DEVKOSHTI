Shipping

I push code. The phone updates itself.

  1. Push to main

    Every change starts as a commit.

  2. Test and build

    GitHub Actions runs the tests and builds the release.

  3. Publish

    The release goes up with a SHA-256 checksum.

  4. Phone checks in

    Every 5 minutes it looks for a newer release.

  5. Swap safely

    It backs up the current version and data, then installs.

  6. Roll back

    If the new version fails its health check, the old one comes back.
