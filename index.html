Shipping

How a change reaches the phone

I push code; the phone updates itself. Nobody has to touch the server, and a bad release can't take the store down.

  1. Push to main

    Every change starts as a commit on GitHub.

  2. Test and build

    GitHub Actions runs the tests and builds the server and website.

  3. Publish a release

    The build goes up as a release with a SHA-256 checksum.

  4. Phone checks in

    Every 5 minutes the phone looks for a newer release and verifies the download.

  5. Swap with a backup

    It saves the current version and data, installs the new one and restarts.

  6. Roll back if needed

    If the health check fails, it restores the saved version and skips that release.
